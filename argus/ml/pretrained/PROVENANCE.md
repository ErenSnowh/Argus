
## Training Status

This checkpoint is trained on **synthetic data** generated by
`ml/world_model/features.py:generate_temporal_dataset()`. It is a
**demonstration checkpoint** that proves the full neural pipeline runs
end-to-end (training → inference → SHAP → dashboard).

The synthetic data is well-separated by design, so the 3-way benchmark shows
near-perfect scores for all three models. The meaningful comparison against
LR/RF baselines (PR-AUC lift, early warning lead time, FPR on minority classes)
will be measured when the model is retrained on real CIC-IDS-2017 data (WP6).
